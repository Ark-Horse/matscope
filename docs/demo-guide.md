# 3–5 分钟演示流程

1. 在材料探索页介绍真实数据集和性能地图，搜索 `Si`，查看硅的立方与六方结构，比较空间群与性质。主数据集只含一个 TiO₂ 条目，不使用它演示多晶型对照。
2. 进入晶体结构页，旋转原子模型，切换 2×2×2 超胞。用晶格尺度滑块更新几何参数，观察衍射峰位置变化。说明这是未弛豫的几何模拟。
3. 返回材料探索，清空搜索并选择默认的硅 `Si`（有谱库标记的结构）。进入衍射分析，点击“加载加噪演示谱”，查看原始谱、预处理谱和模拟谱。
4. 展示 Top-5 候选，点击其他候选，查看叠加谱差异。说明相似度不是概率，候选来自有限谱库。
5. 进入性能预测，从“独立测试样本”下拉框选中一个材料，运行预测，对比 K/G 与 DFT 参考值，并展示整体测试集误差。
6. 打开预测报告，展示打印保存 PDF；在分析记录中恢复之前的谱图检索。
7. 如需证明文件导入，下载页面提供的 CIF 和模拟谱样例，然后分别上传。

## 演示前检查

- 运行 `start.cmd`，访问 `http://127.0.0.1:8000`。
- 首次克隆后的启动会自动训练本地模型；等待 API 显示服务已连接。
- 使用支持 WebGL 的 Chrome 或 Edge。三维资源由本地服务提供。
- 关闭浏览器可能开启的翻译插件，避免自动改动公式。

## 可以准确宣称的功能

真实结构数据；pymatgen 正向 XRD 计算；上传谱图预处理与有限谱库检索；ExtraTrees 弹性性质预测；按化学式分组的独立评估；交互图形、三维结构和结果导出。

XRDecoupler 是后续接入方向，当前页面明确显示尚未部署。不要把本平台的基础匹配算法称为该论文模型，也不要声称已实现任意未知物相结构解析。
